# Snake Game (Python Turtle)

A simple Snake Game made with Python and the Turtle graphics module.

The player controls the snake using the keyboard, collects food, and tries to survive as long as possible without hitting the wall or its own tail.

This project was built using object-oriented programming principles and multiple Python files for better structure and organization.

---

## Features

- Snake movement
- Food spawning system
- Score tracking
- Collision detection
- Keyboard controls
- Object-oriented structure
